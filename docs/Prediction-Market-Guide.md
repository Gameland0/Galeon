# Trade Prediction Market — 产品文档

## 概述

Trade Prediction Market 是一个链上对赌预测平台，用户预测 Galeon Brain AI 交易系统实时持仓的最终盈亏结果（PnL%），猜中即可瓜分奖池。

**核心玩法：** AI 开仓 → 用户预测最终 PnL% → AI 平仓 → 系统自动结算 → 赢家按投注额比例分奖池

---

## 规则说明

### 基本规则

| 项目 | 说明 |
|------|------|
| 预测对象 | Galeon Brain AI 的实时合约持仓 |
| 预测内容 | 该笔交易最终的盈亏百分比（PnL%） |
| 中奖条件 | 预测值与实际 PnL% 的误差 ≤ ±2% |
| 奖金分配 | 所有中奖者按投注金额比例瓜分 98% 奖池 |
| 平台手续费 | 2%（下注时扣除） |
| 投注币种 | USDC（Base 链） |
| 投注范围 | $1 ~ $500 |
| 预测范围 | -20% ~ +200% |

### 中奖逻辑

**举例：** 实际 PnL = +5.0%

- 预测 +4.0%（误差 1.0%）→ ✅ 中奖
- 预测 +6.5%（误差 1.5%）→ ✅ 中奖  
- 预测 +8.0%（误差 3.0%）→ ❌ 未中奖
- 预测 -2.0%（误差 7.0%）→ ❌ 未中奖

### 奖金计算

```
你的奖金 = 奖池总额 × 98% × (你的投注额 / 所有中奖者投注总额)
```

例：奖池 $1000，3 个赢家分别投 $100、$50、$50
- 赢家 A（投 $100）：$1000 × 98% × 100/200 = **$490**
- 赢家 B（投 $50）：$1000 × 98% × 50/200 = **$245**
- 赢家 C（投 $50）：$1000 × 98% × 50/200 = **$245**

### 特殊情况

| 情况 | 处理 |
|------|------|
| 无人中奖（所有预测误差 > 2%） | 奖池进入储备池，用于日后交易激励及平台奖励 |
| 全员中奖（所有参与者都中奖） | 退回每人投注额（手续费不退） |
| 赢家太多导致赢家反亏 | 自动退回每人投注额（手续费不退） |
| 参与人数 < 2 | 自动取消，退回投注额 |
| 持仓已平仓 | 下注锁定，不接受新投注 |

### 费用说明

| 项目 | 费用 | 说明 |
|------|------|------|
| 平台手续费 | 投注额的 2% | 下注时扣除，不可退还 |
| Gas 费 | 约 $0.01 ~ $0.05 | Base 链，用户支付 |
| 结算 Gas | 免费 | 平台承担 |

### 储备池

当某场预测无人猜中（所有预测值误差超过 ±2%）时，该场奖池将全额转入储备池。储备池资金将用于：

- 交易激励活动（如高质量预测者奖励）
- 平台运营奖励
- 社区回馈活动

## 操作步骤

### 第一步：连接钱包

1. 打开 [https://galeon.world/#/prediction](https://galeon.world/#/prediction)
2. 点击右上角 **Connect Wallet**
3. 选择 MetaMask 或其他支持的钱包
4. 确保钱包切换到 **Base** 网络
5. 钱包内需要有 **USDC**（Base 链上的 USDC）和少量 **ETH** 用于 Gas 费

### 第二步：查看 Live 预测事件

1. 在 **Live** 标签页中查看当前正在进行的持仓
2. 每张卡片显示：
   - **币种**（如 ETHUSDT）
   - **方向**（LONG 做多 / SHORT 做空）
   - **杠杆倍数**（如 10x）
   - **入场价格** 和 **当前价格**
   - **实时 PnL%**
   - **参与人数** 和 **奖池金额**
   - **Win Zone ±2%**

### 第三步：下注预测

1. 点击 **Predict Now** 按钮
2. 填写两个字段：
   - **Final PnL% Prediction**：输入你预测的最终盈亏百分比
     - 正数 = 盈利（如 +5.0 表示预测最终赚 5%）
     - 负数 = 亏损（如 -3.0 表示预测最终亏 3%）
   - **Bet Amount (USDC)**：输入投注金额（$1 ~ $500）
3. 点击 **Confirm Bet**

### 第四步：链上确认

下注需要 3 步链上操作（MetaMask 会弹窗确认）：

1. **Connect** — 自动连接到 Base 网络
2. **Approve** — 授权合约使用你的 USDC（首次需要）
3. **Submit** — 提交下注到链上

等待链上确认后，显示 **Bet placed successfully**

### 第五步：等待结算

- AI 平仓后系统自动结算，无需任何操作
- 结算完成后可在 **Settled** 标签页查看结果
- 如果中奖，奖金自动转入你的钱包（通常在平仓后 1-2 分钟内到账）

## 页面功能说明

### Live
显示所有正在进行的持仓预测事件，可以下注参与。

### Settled
显示已结算的历史事件，点击展开可查看：
- 实际 PnL 结果
- 赢家列表及各自奖金
- 所有参与者的预测值和距离

### My Bets
显示你的个人投注记录：
- 投注历史（币种、预测值、实际结果、净盈亏、参与时间）
- 汇总统计（总投注次数、胜率、净 P&L、最佳连胜）

### Leaderboard
全平台玩家排行榜，按净盈亏排序：
- 前 3 名独立展示
- 显示地址、投注次数、胜场、胜率、净 P&L

## 常见问题

**Q: 我预测的值其他人能看到吗？**
A: 可以。当前版本预测值在链上是公开的。

**Q: 同一个事件可以下注多次吗？**
A: 不可以。每个钱包地址对每个事件只能下注一次。

**Q: 下注后可以取消吗？**
A: 不可以。下注上链后不可撤销。

**Q: 为什么显示 "This prediction event is not yet on-chain"？**
A: 该事件的链上创建还在进行中，请稍等几秒后重试。

**Q: 为什么显示 "Please switch to Base network"？**
A: 你的钱包当前不在 Base 网络，请在 MetaMask 中切换到 Base。

**Q: 中奖后奖金什么时候到账？**
A: 结算完成后自动转入你的钱包，通常在持仓平仓后 1-2 分钟内。

**Q: 如果没有人中奖怎么办？**
A: 奖池全部进入储备池，用于日后交易激励及平台奖励。

**Q: 手续费可以退吗？**
A: 不可以。2% 手续费在下注时扣除，即使事件取消也不退还。

**Q: 投多的人是不是更容易赢？**
A: 投多不影响是否中奖（中奖只看预测准不准），但中奖后投注额大的人分到的奖金比例更高。
