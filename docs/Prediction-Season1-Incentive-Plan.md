## 3. Participation Rewards — 550,000 Points

**Recipients: All valid participants (no cap on headcount)**

### 3.1 Formula

```
Participation Points = Valid Predictions × 10 × Amount Multiplier
```

### 3.2 Amount Multiplier

| Bet Amount | Multiplier |
|------------|------------|
| $1 – $9.99 | 1x |
| $10 – $49.99 | 1.5x |
| $50 – $99.99 | 2x |
| $100+ | 2.5x (max) |

### 3.3 Examples

| User | Predictions | Amount Each | Calculation | Points |
|------|-------------|-------------|-------------|--------|
| A | 10 | $5 | 10 × 10 × 1.0 | 100 |
| B | 10 | $30 | 10 × 10 × 1.5 | 150 |
| C | 10 | $120 | 10 × 10 × 2.5 | 250 |

### 3.4 Caps

| Rule | Value |
|------|-------|
| Minimum bet amount | $1 |
| Daily points cap | 2,000 Points / user |
| Season points cap | 150,000 Points / user |
| Only settled pools count | Canceled / refunded / abnormal excluded |

### 3.5 Distribution Method

At the end of the season, 550,000 Points are distributed pro-rata:

```
User Reward = 550,000 × (User Participation Points / Total Platform Participation Points)
```

## 6. Accuracy Bonus — 100,000 Points

**Recipients: Top 200**

### 6.1 Ranking Metric

```
Prediction Error = |Predicted PnL% − Actual PnL%|
Accuracy Score   = Sum of all errors / Number of valid predictions
```

Lower average error = higher rank.

### 6.2 Example

| Predicted | Actual | Error |
|-----------|--------|-------|
| +5.0% | +4.8% | 0.2 |
| -3.0% | +2.0% | 5.0 |
| +1.5% | +1.2% | 0.3 |

Average Error = (0.2 + 5.0 + 0.3) / 3 = 1.83
